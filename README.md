# ワーホリ貯金トラッカー

`index.html` 1ファイルで動く貯金トラッカーです。ブラウザで開くだけで使え、記録はブラウザ（localStorage）に保存されます。

## 機能
- 目標額の選択（AUD 7,000 基準 / 95万（最低ライン） / 110万 / 120万）
- 最低ライン95万円までの残額・達成表示（進路の線上に旗）
- 2026年10月〜2027年3月の月別貯金の記録
- 為替レートを入力して豪ドル換算・現地到着時の手元資金を表示
- 出発前の支払いチェックリスト

## PWA（ホーム画面に追加・オフライン対応）
- `manifest.json` … アプリ名・アイコン・テーマ色の定義
- `sw.js` … サービスワーカー。初回表示時にファイルをキャッシュし、以後はオフラインでも起動します
- `icons/` … 飛行機モチーフのアイコン（`icon.svg` が元データ、PNGはそこから書き出し）

サービスワーカーは `https://`（または `localhost`）でしか動かないため、ファイルを直接開くのではなく下記のようにホスティングして使います。
アプリを更新したら `sw.js` の `CACHE` の番号（`wh-savings-v1` → `v2`）を上げてください。

## 無料でホスティングする（GitHub Pages）
1. GitHub のリポジトリページで **Settings → Pages** を開く
2. **Build and deployment** の Source を「Deploy from a branch」にする
3. Branch で公開したいブランチ（例: `main`）と `/ (root)` を選んで **Save**
4. 1〜2分待つと `https://<ユーザー名>.github.io/wh-savings/` で公開されます
   ※ 無料プランで GitHub Pages を使うにはリポジトリが **Public** である必要があります

### ホーム画面に追加
- **iPhone（Safari）**: 公開URLを開く → 共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**: 公開URLを開く → メニュー（︙）→「ホーム画面に追加」/「アプリをインストール」

記録は端末ごとのブラウザ（localStorage）に保存されます。iPhone ではホーム画面のアプリと Safari の保存領域が別なので、ホーム画面から使い始めるのがおすすめです。

### ほかの無料ホスティング
- **Netlify Drop**: https://app.netlify.com/drop にフォルダをドラッグ＆ドロップ
- **Cloudflare Pages**: GitHub リポジトリを連携して、ビルド設定なしで公開

## Claude Code に渡すプロンプト例

### スマホのホーム画面に置けるアプリ（PWA）にする
```
このフォルダの index.html をPWAにしてください。
manifest.json とサービスワーカーを追加して、オフラインでも動き、
iPhone/Androidのホーム画面に追加できるようにしてください。
アイコンは飛行機をモチーフに作成してください。
最後に無料でホスティングする方法（GitHub Pages など）も手順を教えてください。
```

### ネイティブアプリ（iOS/Android）にする
```
このフォルダの index.html の機能を、Expo（React Native）のアプリとして作り直してください。
データは端末内に保存（AsyncStorage）し、デザインと計算ロジックは元のHTMLに合わせてください。
Expo Go で自分のスマホで試すまでの手順も教えてください。
```
