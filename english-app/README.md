# Hello Coach — 自分専用のAI英会話スクール

AI講師との **リアルタイム音声英会話** を中心に、会話後のAIフィードバック、英文法問題、英作文添削、学習記録・復習をひとつにまとめた個人用の英語学習Webアプリです。

> **現在の状態：Phase 1（MVP）・Phase 2（学習機能の強化）・Phase 3（完成度の向上）がすべて完成しています。**
> 実装済みの機能・未実装の機能は「[機能一覧と実装状況](#機能一覧と実装状況)」に正直に書いています。

## システム構成

```
┌──────────── ブラウザ（PC / スマホ） ────────────┐
│  Next.js + React 画面                         │
│                                               │
│  AI英会話：マイク音声 ⇄ WebRTC ⇄ OpenAI Realtime API（音声の往復はブラウザとOpenAIの直接通信 → 低遅延）
│            ↑ 一時キー（10分で失効）だけを受け取る │
└───────────────┬───────────────────────────────┘
                │ /api/...（自分のサーバー）
┌───────────────▼──────────── Next.js サーバー ──┐
│  ・一時キーの発行（本物のAPIキーはここだけ）    │
│  ・添削 / 採点 / 問題作成 / 会話レポート        │ → OpenAI Responses API（構造化出力）
│  ・学習記録の保存                               │ → SQLite（data/app.db）
└───────────────────────────────────────────────┘
```

### 採用した技術と理由

| 用途 | 採用 | 理由 |
| --- | --- | --- |
| リアルタイム音声会話 | **OpenAI Realtime API（`gpt-realtime`）+ WebRTC** | 音声を直接理解して音声で返すため、「音声認識→文章生成→音声合成」を順番に行う方式より遅延が小さく、相づちや割り込みも自然。WebRTC はブラウザ標準で、エコー除去も効く |
| 話し終わりの検出・割り込み・沈黙時の声かけ | Realtime API の `server_vad`（`interrupt_response` / `idle_timeout_ms`） | サーバー側で処理するので確実で、ブラウザ側の実装がシンプル |
| あなたの発話の文字起こし（字幕・レポート用） | `gpt-4o-mini-transcribe` | 安価で日本語混じりの発話も認識できる |
| 添削・採点・問題作成・レポート | `gpt-5.4-mini`（Responses API + Structured Outputs） | JSON の形を強制できるので画面表示が壊れない。安価で速い |
| 画面 | Next.js 16 / React 19 / TypeScript / Tailwind CSS v4 / shadcn/ui 形式のコンポーネント | 指定どおり |
| データベース | SQLite（better-sqlite3）+ Drizzle ORM | ファイル1つで動き、セットアップ不要。Drizzle なので将来 PostgreSQL へ移行しやすい |
| 認証 | 任意のパスワード保護（`APP_PASSWORD`） | 個人利用向け。全テーブルに `user_id` 列があり、将来のログイン機能に拡張できる |

**APIキーの安全性**：OpenAI の APIキーはサーバー側の `.env.local` にだけ置かれます。音声会話では、サーバーが **10分で失効する一時キー** を発行してブラウザに渡すため、本物のキーがブラウザに出ることはありません。

モデルは `.env.local` で変更できます（例：料金を抑えたいときは `OPENAI_REALTIME_MODEL=gpt-realtime-mini`）。

## はじめての起動（Mac）

### 1. Node.js をインストール（初回だけ）

1. https://nodejs.org/ja を開き、**「LTS」版** をダウンロードしてインストールします（バージョン 20.9 以上が必要）。
2. 「ターミナル」アプリを開きます（Finder →「アプリケーション」→「ユーティリティ」→「ターミナル」）。
3. 次のコマンドを貼り付けて Enter。バージョン番号（例 `v22.x.x`）が出ればOKです。

```bash
node -v
```

### 2. OpenAI の APIキーを用意（初回だけ）

1. https://platform.openai.com/ にログイン（アカウントがなければ作成）。
2. 「Billing」で支払い方法を登録し、少額をチャージします（APIは前払い制です）。
3. https://platform.openai.com/api-keys で「Create new secret key」を押し、表示された `sk-...` をコピーします（**他人に見せないでください**）。

### 3. プロジェクトを準備（初回だけ）

ターミナルで、このフォルダ（`english-app`）に移動します。
例：デスクトップに `wh-savings` を置いた場合

```bash
cd ~/Desktop/wh-savings/english-app
```

必要なパッケージをインストールします（数分かかります）。

```bash
npm install
```

設定ファイルを作成します。

```bash
cp .env.example .env.local
open -e .env.local
```

テキストエディットが開くので、`OPENAI_API_KEY=` の後ろにコピーしたキーを貼り付けて保存します。

```
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

### 4. 起動

```bash
npm run dev
```

`Ready` と表示されたら、ブラウザ（Chrome / Safari / Edge）で **http://localhost:3000** を開きます。

- 止めるとき：ターミナルで `Control + C`
- 次回からは `cd ~/Desktop/wh-savings/english-app` → `npm run dev` だけでOK
- `.env.local` を変更したら、一度止めて `npm run dev` で起動し直してください

> APIキーを設定していなくても起動できます。その場合は画面上部に設定方法が表示され、AIを使う機能のボタンは押せなくなります（学習記録・復習・設定は使えます）。

### 毎日使うなら（少し速い本番モード）

```bash
npm run build
npm start
```

## 各機能の試し方

### ① AI英会話（最重要機能）

1. 左メニュー（スマホは下のタブ）の **「AI英会話」** を開く
2. 会話モード（フリートーク / 日常英会話 / カフェ / 海外旅行 / ロールプレイ / ディスカッション / 文法実践）と場面を選ぶ
3. 必要なら「場面の詳細」に自分だけのシチュエーションを書く（例：スペシャルティコーヒー専門店で豆の産地を聞かれる）
4. AI講師（Emma / Leo / Mia / Noah）と接し方（フレンドリー / やさしく丁寧 / しっかり指導 / くだけた会話）を選び、必要なら「講師へのお願い」を書く（例：サッカーの話題が好き）
5. レベル・時間・話す速度・アクセント・添削のタイミング・**話す順番**・日本語サポートを選ぶ
   - 話す順番：「自動（標準）」／「自動（考える時間長め）」＝言いよどんでも待ってくれる／「押して話す」＝周りがうるさい場所向け（ボタンまたはスペースキーを押している間だけ話す）
6. **「会話を始める」** → ブラウザがマイクの許可を求めるので「許可」
7. AI講師が挨拶と質問をしてくるので、英語で答えます

試してほしいこと：
- **割り込み**：AIが話している途中で話し始めると、AIが話すのをやめてあなたの話を聞きます（✋ボタンでも止められます）
- **沈黙**：しばらく黙っていると、AIが答えやすい質問をしてくれます
- **日本語で質問**：「『甘さ控えめ』って英語でどう言えばいい？」と日本語で聞くと、英語表現を教えてくれます
- **字幕**：右上の字幕ボタンで英語字幕の表示／非表示を切り替え
- **マイク**：中央の大きなボタンでマイクの ON/OFF
- **キーボード**：⌨ボタンで文字入力もできます（声を出せない場所で便利）
- **ヒント**：💡ボタンで、AI講師の質問への返答例を3つ（短い答え・詳しい答え・質問を返す答え）表示します。会話は止まりません
- **マイクレベル**：講師の下の小さなバーで、声がマイクに届いているか確認できます
- **ショートカット（PC）**：M キーでマイクON/OFF、押して話すモードではスペースキー長押しで話す
- **接続が切れた場合**：自動で1回再接続し、それまでの会話内容を引き継ぎます。失敗したら「再接続」ボタンが出ます

> イヤホン・ヘッドホンの使用をおすすめします。スピーカーだとAIの声をマイクが拾い、AIが自分の声に反応することがあります。

### ② 会話後のAIフィードバック

会話を終了（赤いボタン）すると、自動でレポート画面に移動し、10〜40秒ほどでレポートが作られます。

- 会話の要約、文字起こし
- 文法ミス・不自然な表現・語彙の改善を「【自分が話した英文】【より自然な英文】【解説】【関連する表現】」の形式で表示
- よく使えた表現、次回の改善ポイント、復習したいフレーズ5個（🔊で読み上げ）
- 評価：文法・語彙・流暢さ・会話の継続力（**発音は音声分析をしていないため評価しません**）
- 発言回数・語数・1回あたりの語数・発話時間の割合・話す速さ（実測値）
- **「もう一度練習する」**：間違えた表現を使わせるように、AI講師が会話を組み立て直します
- 添削された英文は自動で「復習」に登録されます

### ③ 英文法問題

1. 「英文法」→ 文法カテゴリ（16分野）・難易度（初級/中級/上級）・問題数・形式を選んで「問題を作成して始める」
2. 形式：和文英訳 / 4択 / 空欄補充 / 並べ替え / 誤文訂正（「ミックス」で混ぜて出題）
3. 各問10点満点。模範解答と同じなら即座に満点、違う場合はAIが **意味と文法で** 採点し、部分点・解説・別の正しい言い方を表示
4. 8点未満の問題は自動で「復習」に登録
5. **「苦手克服ドリル」**：一番苦手な分野を自動で選び、最近の間違い（英会話・英作文・文法問題）と同じ文法ポイントの新しい問題をAIが作ります

### ④ 英作文添削

- 「添削」タブ：英文を入力 → 添削レベル（基本文法のみ / 自然な日常英会話 / ネイティブらしい表現 / 丁寧なビジネス英語）を選んで「添削する」。修正前後の比較（削除は赤、追加は緑）、修正理由、より自然な表現を表示
- 「日本語→英語」タブ：日本語を入力すると、自然な英訳・別の言い方・文法解説を表示
- 「履歴」タブ：過去の添削・翻訳を開いて見返せます

### ⑤ 学習記録と復習

- **ホーム**：今日の学習時間、連続学習日数、今日の復習数、文法の正答率、今日のおすすめ学習、前回の続き
- **学習記録**：今週の目標（週の学習時間・変更可）、学習時間グラフ（日別30日／週別12週）、英会話スコアの推移、苦手な文法ランキング、分野別の正答率、英会話・英作文の履歴
- **苦手分野の判定**：文法問題の誤答だけでなく、英会話・英作文でAIが指摘した間違いも文法カテゴリに自動分類して数えます
- **復習**：英会話・文法・英作文の間違いが登録され、**翌日以降、忘れかけたタイミングで出題**されます。答えを入力して「AIで採点する」を押すと採点・解説とおすすめの自己評価が出ます。「もう一度 / 難しい / できた / 簡単」で自己評価すると、次の出題日が自動で決まります（間隔反復）

### ⑥ AI学習プランナー

ホームの「今日のおすすめ学習」で学習時間（5/15/30/60分）を選び、**「AIでプランを作る」** を押すと、AIがあなたの学習データ（期限の来た復習、苦手分野、前回の英会話の改善ポイント、スコアの推移、今週の目標など）を分析して、**理由つき** のメニューを作ります。

- 各項目を押すと、その設定で始められます（例：英会話はモード・場面・時間が選択済み、英作文はお題つき、文法は苦手克服ドリル）
- 作ったプランはその日のあいだ保存され、何度開いてもAI料金はかかりません（「作り直す」で再作成）
- APIキーがない場合やプランを作る前は、ルールに基づく簡易プラン（無料）が表示されます

### ⑦ 学習傾向の分析

「学習記録」の「学習傾向の分析」で、よく学習する時間帯（時間帯別グラフ）、学習した日の平均時間、英会話スコアと1回に話す語数の変化を表示します。「AIで分析する」を押すと、伸びている点・課題・来週やることをAIがまとめます（1日1回保存）。

### ⑧ 設定・ホーム画面に追加

右上（PCは左下）の⚙から：APIの設定状況、文字起こしを保存するかどうか、学習データの書き出し（JSON）、文字起こし／全データの削除、**ホーム画面に追加**（アプリのように全画面で起動。https で開いているときに使えます）。

ホーム画面に追加すると、ネットワークが切れても一度開いた画面は表示でき、未表示の画面ではオフラインの案内が出ます（AI機能と記録の保存には接続が必要です）。

## スマホで使う

ブラウザは **安全な接続（https）でないとマイクを使えません**。`http://localhost` はPC自身からのアクセスだけが例外です。スマホで使うには、次のどちらかの方法をとります。

### 方法A：同じWi-Fiのスマホから（手軽・自分専用）

1. Mac で次のコマンドで起動します（初回は証明書を作るため、Macのパスワードを聞かれることがあります）

   ```bash
   npm run dev:https
   ```

2. Mac の IPアドレスを調べます：「システム設定」→「Wi-Fi」→ 接続中のネットワークの「詳細」→「IPアドレス」（例 `192.168.1.23`）
3. スマホのブラウザで `https://192.168.1.23:3000` を開きます
4. 「この接続ではプライバシーが保護されません」等の警告が出たら、「詳細を表示」→「このWebサイトを閲覧」で進みます（自分のMacの自己署名証明書のため）

> 同じWi-Fiにいる他の人もアクセスできてしまうので、`.env.local` に `APP_PASSWORD=好きなパスワード` を設定しておくと安心です。

### 方法B：インターネットに公開する

Railway / Render / Fly.io などの「ファイルを保存できる」サーバーに置く方法があります。**公開する場合は必ず `APP_PASSWORD` を設定してください**（他人にAPIを使われ、料金が発生するのを防ぐため）。
※ Vercel などのサーバーレス環境では SQLite のファイルが保存され続けないため、学習記録が消えます。その場合は PostgreSQL への移行が必要です（Drizzle ORM を使っているので移行しやすい構造になっています）。

## 料金（API利用量）について

最新の料金は https://openai.com/api/pricing で確認してください。目安と工夫：

- **最も料金がかかるのは音声会話** です（音声の入出力はテキストより高価）。時間設定（5〜25分）で使いすぎを防げます。安く使いたい場合は `.env.local` で `OPENAI_REALTIME_MODEL=gpt-realtime-mini` を指定してください
- AI講師の発話を短くする指示にしているため、AIの音声出力（高価な部分）が少なくなります
- 文法問題は、模範解答と一致する答え・4択はAIを使わずにアプリ内で採点します（AIは別解の判定にだけ使用）
- 添削・採点・問題作成は安価な `gpt-5.4-mini` を使用
- AI学習プランは1日1回作れば保存され、開くたびに料金はかかりません。簡易プランや読み上げ（🔊、ブラウザ内蔵の音声合成）は無料
- 復習の「AIで採点する」は、模範解答と一致すればAIを使わずに正解と判定します
- OpenAI の管理画面（Usage / Limits）で **月の上限金額** を設定しておくと安心です

## プライバシーとデータ

- 学習データは Mac 内の `data/app.db`（SQLite）だけに保存されます
- **音声そのものは保存しません**。会話中の音声は処理のため OpenAI に送信されます
- 添削・採点・レポートのリクエストは `store: false`（OpenAI 側に保存しない設定）で送信しています
- 設定画面で「英会話の文字起こしを保存する」を OFF にすると、レポート作成後に文字起こしを削除します
- 設定画面から、学習データの書き出し（JSON）・文字起こしの一括削除・全データ削除ができます

## テスト

```bash
npm test          # 採点・間隔反復・日付・差分・発話データ・AI講師の指示などの単体テスト
npm run lint      # コードのチェック
npm run typecheck # 型チェック
```

**E2Eテスト（画面を実際に操作するテスト）**：本物の OpenAI の代わりに「偽の OpenAI」を使うので、APIキーも料金も不要です。

- `realtime.e2e.cjs`：AI英会話。別タブに偽の Realtime サーバーを作り、実際の WebRTC 接続・字幕・テキスト入力・接続切れからの自動再接続・終了→レポートまで確認
- `pages.e2e.cjs`：英文法（5形式）・英作文・学習記録・設定・スマホ表示・ダークモード
- `phase2.e2e.cjs`：復習のAI採点、苦手克服ドリル、ダッシュボード、AI学習プラン→各画面へのリンク、講師設定
- `phase3.e2e.cjs`：押して話す（ボタン・スペースキー・短すぎる押下）、返答ヒント、学習傾向の分析、404画面、PWA（マニフェスト・アイコン・オフライン表示）

```bash
npx playwright install chromium   # 初回だけ（テスト用ブラウザのダウンロード）
npm run build
npm run test:e2e
```

スクリーンショットは `e2e/screenshots/` に保存されます。

> 本物の OpenAI との音声会話そのもの（音質・遅延・AIの返答内容）は、APIキーを設定して実際に話して確認してください。

## 困ったときは

| 症状 | 対処 |
| --- | --- |
| 画面上部に「APIキーが設定されていません」 | `.env.local` に `OPENAI_API_KEY=sk-...` を書いて保存し、`Control + C` → `npm run dev` で再起動 |
| 「APIキーが無効です」 | キーのコピー漏れ・前後の空白を確認。キーを作り直すのも有効 |
| 「利用上限に達した」 | OpenAI の Billing で残高・上限を確認 |
| 「モデルが見つからない」 | アカウントでそのモデルが使えない可能性。`.env.local` で `OPENAI_REALTIME_MODEL` / `OPENAI_TEXT_MODEL` を別のモデルに変更 |
| マイクが使えない | 画面の案内に従ってブラウザ・Mac のマイク許可をONに。Zoom 等がマイクを使っていないか確認 |
| AIの声が聞こえない | 音量・出力先を確認。iPhone はマナーモードを解除し、画面を一度タップ |
| AIが自分の声に反応してしまう | イヤホンを使用 |
| スマホでマイクが使えない | 「[スマホで使う](#スマホで使う)」の https での起動を参照 |
| `npm install` で better-sqlite3 のエラー | Node.js を LTS 版で入れ直す。それでもダメなら `xcode-select --install` を実行してから再度 `npm install` |
| ポート 3000 が使用中 | `npm run dev -- -p 3001` で起動し、http://localhost:3001 を開く |
